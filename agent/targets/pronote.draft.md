# PRONOTE 2026 (client Windows, Index Education): saisie des appréciations des professeurs par matière dans le bulletin (Bulletins > Saisie des appréciations)

> **Draft from official documentation, not yet verified against the application.**

## Procedure

1. Ouvrez **Bulletins > Saisie des appréciations > Saisie des appréciations des professeurs par matière**.
2. Sélectionnez le service dans la liste de gauche, puis la période dans le menu déroulant.
3. Sur la ligne de l’élève, double-cliquez dans la colonne **Appréciations**, puis saisissez le commentaire. La documentation fournie ne précise ni bouton **Enregistrer**, ni message de confirmation, ni étape de validation à la sauvegarde. Elle indique que les appréciations saisies dans le bulletin sont automatiquement reportées dans le bilan périodique, et inversement.
