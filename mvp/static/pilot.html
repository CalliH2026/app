Connectez votre PRONOTE

Ouvrez votre espace habituel ou connectez votre compte pour retrouver automatiquement les données disponibles.

Dans le client officiel, ajoutez le serveur et son port, puis connectez-vous avec votre compte professeur ou le parcours ENT de l’établissement. Aucun mot de passe n’est demandé ici.

La lecture visuelle peut relever des données d’élèves : ouvrez uniquement la vue utile, après la connexion. Les relevés restent dans le dossier local de l’application. Ce pilote ne les transmet pas automatiquement à H, Gladia ou Linkup.

Le navigateur dédié est séparé de votre navigateur habituel. Connectez-vous directement dans PRONOTE ou l’ENT puis revenez sur l’espace professeur configuré. La lecture automatique de la vue ouverte commence après votre confirmation ci-dessous.

Le relevé récupère le texte visible. Les pièces jointes, grilles dessinées et iframes peuvent rester illisibles.

Vérification du contexte réel

Aucun relevé.

Si le texte ne contient pas la copie ou le barème, ces pièces n’ont pas été récupérées. Aucun rapport pédagogique complet ni vidéo n’est généré par ce pilote.
