# Rules for agents working in this repository

Project: Calli. New Pronote is the interface; Calli is its assistant. The unified product includes native PRONOTE dictation, sourced preparations, Devin API practice activities, outing tools and a read-only family view. Read README.md and docs/calli-api-and-architecture.md first. SPEC.md records the initial Calligraphe design; current behavior takes precedence over that historical scope.

- Language: English for code, comments, docs and commits.
- Tests first: every module ships with pytest tests that run without network access and without API keys.
- No secrets, ever: no API keys, tokens or passwords in code, tests, fixtures, docs or commit messages. Keys are read from environment variables at runtime (HAI_API_KEY, GLADIA_API_KEY). Never print them.
- No real personal data: students, teachers and comments are fictitious and generated by data/make_roster.py.
- Never simulate results: the README scoreboard is generated from files in runs/ by scripts/report.py; empty until a real run exists.
- One pull request per module, small and reviewable, with a description that lists what was tested and what was not.
- Do not change agent/targets/*.md (the per-target click paths) without a human: they are verified by hand on the real software.
- Python 3.10 or newer, uv or pip, ruff for lint. Keep dependencies minimal.
