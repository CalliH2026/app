# PRONOTE import files (fictitious data)

Files in this folder:

| File | Content |
|---|---|
| `eleves.txt` | 10 students, tab-separated, header row `Nom`, `Prénom`, `Classe` |
| `eleves.csv` | same rows, `;`-separated |
| `professeurs.txt` | 1 teacher, tab-separated, header row `Nom`, `Prénom`, `Matière` |
| `professeurs.csv` | same row, `;`-separated |

All names are fictitious. They were generated by
[`scripts/pronote/make_import_files.py`](../make_import_files.py) from `data/roster.csv`
(`student_id, display_name, aliases`, SPEC.md section 5), itself produced by `data/make_roster.py`.
The roster keeps the demo traps: two students named Lucas (BERNARD and PETIT), two homophone first
names (Gaël LAMBERT and Gaëlle FONTAINE), one nickname (Maximilien GARNIER, "Max"). If
`data/roster.csv` is missing, the script falls back to a built-in fictitious roster. Regenerate
after any roster change:

```bash
python scripts/pronote/make_import_files.py
```

`tests/test_pronote_import_files.py` fails if the committed files drift from the generator.

## Format status: no fixed PRONOTE layout is documented publicly

What the official documentation says:

- Data can be imported "depuis un fichier Excel ou tout autre tableur par copier-coller (ou via la
  commande Imports/Exports > TXT/CSV/XML > Importer un fichier texte)"; in the import window you
  check the "type de données à importer", select the field separator "Tabulation", map each column
  to a PRONOTE field ("Champ ignoré" for columns to skip), tick "Ne pas importer les x premières
  lignes" for header rows, optionally save the format, then click "Importer".
  Source: <https://docs.index-education.com/docs_fr/fr-pronote-support-fiche-323-1868-comment-completer-la-base-avec-les-donnees-qui-ne-proviennent-ni-de-pronote-ni-d-edt.php>
- The same procedure is described for pasting into a list; it needs the "Mode administratif" and a
  user of the "Administration" group.
  Source: <https://docs.index-education.com/docs_fr/fr-pronote-support-fiche-4032-4187-comment-importer-les-donnees-d-un-tableur-dans-une-liste.php>
- The data types include "Elèves et leurs responsables" and "Responsables uniquement".
  Source: <https://docs.index-education.com/docs_fr/fr-pronote-support-fiche-4070-4439-j-ai-essaye-d-importer-les-responsables-dans-la-base-mais-je-n-arrive-pas-a-associer-plusieurs-responsables-a-un-meme-eleve-.php>
- The EDT/PRONOTE practical guide describes the expected spreadsheet shape as "une ligne par
  donnée, une colonne par type d'information"; required fields not yet mapped show in red.
  This passage is tagged EDT in the guide.
  Source: <https://www.index-education.com/contenu/telechargement/edt/v2026.0/pdf/Guide-Pratique-EDT-PRONOTE-FR-2026.pdf#page=27>

What it does not say: the column names, the mandatory fields for a student or a teacher, the
file encoding expected by "Importer un fichier texte", or the exact label of the student data
type. The column layout is chosen by the user in the import window, so these files are plain
tab-separated text with a header row, not a confirmed native PRONOTE format. The header names
(`Nom`, `Prénom`, `Classe`, `Matière`) are our choice; map them by hand in the import window.

Encoding, verified by hand in PRONOTE Monoposte 2026.2.8 (see `docs/pronote-vm-notes.md`): a
UTF-8 file without a byte-order mark is read as ANSI ("GaÃ«l"); the same file with a BOM imports
the accents correctly. `make_import_files.py` therefore writes UTF-8 with a BOM.

## How to use them (UNCONFIRMED where marked)

Prerequisite: the class `3A` and the subject `FRANCAIS` exist (see `docs/pronote-setup.md`).

1. Open `eleves.txt` in Excel or Notepad, select all rows including the header, copy (Ctrl+C).
   Copy-paste avoids the open encoding question of the text-file import.
2. In PRONOTE, administrative mode, open the student list and paste (Ctrl+V): the import window
   opens. UNCONFIRMED: the student list display is "Ressources > Élèves > Liste"; the pages above
   only say "la liste où vous souhaitez effectuer l'importation".
3. Check the data type (UNCONFIRMED label for students only), separator "Tabulation", map
   `Nom`, `Prénom`, `Classe` to the matching fields (UNCONFIRMED field names), tick
   "Ne pas importer les 1 premières lignes", click "Importer".
4. Repeat with `professeurs.txt` in "Ressources > Professeurs > Liste" (this display is
   documented for adding teachers:
   <https://docs.index-education.com/docs_fr/fr-pronote-support-fiche-1523-1779-mettre-a-jour-les-donnees-des-enseignants.php>).
   `Matière` may have no matching field: leave it "Champ ignoré"; the subject is linked to the
   teacher through the service.

## Manual-entry fallback

If the import refuses the data, type the 11 rows by hand. The guide describes manual entry in a
list as: click the first line ("Créer un professeur / une classe / etc."), fill the fields, and
press Enter after each mandatory field (tagged EDT in the guide; UNCONFIRMED for PRONOTE).
Source: <https://www.index-education.com/contenu/telechargement/edt/v2026.0/pdf/Guide-Pratique-EDT-PRONOTE-FR-2026.pdf#page=28>
