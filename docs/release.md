# Public hackathon release — 8 November 2026

Canonical repository: https://github.com/CalliH2026/app

This is a fresh-history export of the integrated Calli application. It combines the New Pronote workspace, native appreciation writer, parallel preparation, family summary, educational practice, outings, payment adapter and the standalone public preview. It preserves the integrated runtime code and product tests.

The source snapshot is `cc6bc077effa4f7db8947788b43485094762f496`; its application tree was synchronized into François’s integration branch before this export. Public-release changes update documentation, canonical links and packaging only. Runtime module names retained from earlier development are intentional compatibility names.

Included: runnable application, offline tests, fictional fixtures, recorded benchmark journals (including failures), link to the final accepted v14 film, pitch sources and artifacts, architecture diagrams and measurement assumptions.

Excluded: private Git history, environment files, credentials, VM-access notes, WhatsApp/Discord exports, hosting account bindings, obsolete videos, raw production captures and five tests concerned only with discarded historical film compositions. No product tests were removed. Selected older stills and mathematical models remain as inputs for the pitch and benchmark checks; they are not a complete film-rendering project.

The public preview uses saved runs. The full application requires provider configuration and a PRONOTE environment for native execution. Neither the persona switcher nor the preview is a production identity-management system.
