## Project description

Calli is an assistant that works alongside you. It observes context inside a workspace, anticipates a useful next task and combines Holo 4 computer use with function calling to get work done. Our first application is education: New Pronote provides a clearer interface while H operates the existing PRONOTE desktop. Teachers dictate comments, receive sourced preparation and generate interactive practice through the Devin API. Parents get one view for two children. School-trip tools bring research, routes and optional payment into the same workflow. Gladia handles transcription and Linkup provides educational sources.

## How to test

Open the demo without an account. Explore the teacher workspace, open the pupil’s copy, read the sourced report, try the exercise, inspect the school trip and switch to the family view. These are saved results of real runs, with fictional data; no credentials, payment or native writes are required. Use the video for the PRONOTE desktop execution and this repository for the full integrations.
