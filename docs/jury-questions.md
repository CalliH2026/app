# Calli — jury and audience questions

Team preparation · 8 November 2026. Use the short answer first; expand only if asked. Latest evidence: video v10, genuine Devin session `71991d823adc4d4983ab552ced945583`, source-linked H results and the committed run journals.

## The 15-second explanation

**Calli anticipates the next useful task and prepares it while you work. Education is our first application: New Pronote offers a clearer interface, while Holo 4 operates the existing PRONOTE desktop and calls bounded functions.**

French: **Calli anticipe la prochaine tâche utile et la prépare pendant que vous travaillez. Notre première application est l’éducation : New Pronote simplifie l’expérience, Holo 4 pilote PRONOTE derrière et appelle nos fonctions.**

## Why computer use? Why not an API or MCP?

**Short answer:** “We use APIs where they fit. Computer use bridges the native application in this demonstrated workflow.”

We did not alter PRONOTE’s executable or database. In the Windows trial, the agent uses the visible interface to enter, save and read back a comment. MCP can expose an existing capability through a common protocol; someone must still implement that capability, using an API, CLI or computer use. A future MCP wrapper and Holo are compatible choices.

Do **not** say “PRONOTE has no APIs” or “MCP cannot modernize it.” INDEX ÉDUCATION documents export/connectivity services. We have not established that these cover the native comment-writing action in our configured trial. The architecture argument is about the demonstrated integration, not a universal claim about the vendor. [Official PRONOTE exports](https://telechargement.index-education.com/fr/pronote-info1420-services-export-de-donnees.php), [MCP architecture](https://modelcontextprotocol.io/docs/learn/architecture).

## Why not rebuild the whole application?

**Short answer:** “Changing the experience does not have to mean replacing the system of record.”

Recreating a screen is different from replacing established records, workflows, permissions, integrations and deployment. Calli demonstrates a narrower route: improve the interaction, keep the existing application, verify the bounded action. For a greenfield task, rebuilding or an API integration may be the better choice. We have not benchmarked a full migration.

## What does “anticipation” actually mean?

**Short answer:** “An opening event inside Calli starts useful preparation while the person continues.”

Opening the configured pupil document starts preparation against that case and its sources. The family view also supports an opt-in opening trigger and cached results. This is application-level context, not a universal desktop observer. Opening a document does not silently trigger native comment writes; the native action comes from the completed dictation.

## What is truly parallel?

Background assistance overlaps the person’s work. The outing implementation also dispatches independent collectors concurrently. Native PRONOTE writes remain serial, one bounded item at a time. Do not conflate these mechanisms or claim every provider call runs simultaneously. [Architecture and execution sequence](calli-system.md).

## What does Holo 4 add beyond a Python script?

Holo performs visual navigation and computer actions. The managed-agent flows select tools for the preparation and outing tasks. Python supplies the tool contracts, state, identity checks and result comparisons. In the native path, `next_item` gives a bounded task and `report_result` returns the observed pupil/text. The combination turns a computer action into a checked workflow. “Computer use” and “custom tools” are the terminology used in our implementation.

## Where is H Workstation used?

The outing path includes the H Workstation preview for terminal access to research/scripts, alongside custom tools and browser actions. This is different from the Holo desktop native-writer environment. Do not imply the Workstation is required for every Calli operation or that the hackathon preview has guaranteed long-term availability. [Sponsor documentation](https://hub.hcompany.ai/agents-api/workstation).

## Is the new exercise really generated by Devin?

Yes. A fresh product API session generated the HTML on 8 November in about nine minutes. We independently checked 23 functional behaviours and 450 generated triangles across the three specified triples and missing-side cases. The film shows that file in New Pronote’s sandbox. The saved result loads immediately; a new generation takes minutes. The older exercise and v9 remain available as fallbacks.

Devin CLI was also used for engineering and Windows VM provisioning. That is separate from the product’s Cognition/Devin API feature, which matters for the sponsor track.

## Why is Linkup useful for learning?

It retrieves educational material for the sourced preparation. We also used a separate Linkup research pass to ground the generation instructions in learning-science guidance: optional worked examples, an attempted answer and structured reason before correction, specific feedback, varied problems and less help in the final task. The activity suggests returning later; it does not implement a spaced-practice scheduler. The research pass is curated design work, not a new literature review on every click. [Sources and limitations](learning-science-and-impact.md).

## Does this improve attainment?

**“We have implemented research-informed design principles and tested the software. We have not measured learning gains.”**

A next study would compare activities on the same skill, measure completion and error patterns, then use a delayed test. Prior literature supports design choices; it does not validate this particular AI-generated activity.

## How do you know the PRONOTE write succeeded?

The agent leaves the edited field and reads it back. Python compares the reported full name and text with the queued request and journals the outcome. The recorded UI result was inspected. This is useful verification, not a mathematical guarantee: the visual read-back still depends on the agent, so a production study must include difficult layouts, ambiguous names, interruptions and independent spot checks. Failures and unknown outcomes remain explicit.

## Can the human stop or correct it?

STOP prevents new writes. An already-started action may finish; STOP does not undo completed work. Ambiguous identity or invalid input is held for correction. The native comment is the teacher’s dictated content, not an automatically assigned grade. The exercise preview requires teacher review before download.

## Are the time savings measured?

**“The native execution is measured; the human time savings are modelled.”**

One recorded queue-to-verified comment took 25.57 seconds. That is agent elapsed time, not a human comparison. The current video uses a rounded median of **43% less active comment-entry time** from a sensitivity model, with an illustrative 33–52% range. These are not confidence intervals from users. The annual scenario is about 6 hours per teacher, 12 hours per class, 240 hours per 40-teacher school and 3 hours per two-child household. Totals overlap; do not add them. [Model](annual-time-scenarios.md).

## Can we say “30 days saved per school”?

Say **“around 30 eight-hour day equivalents of capacity per school per year, in our scenario.”** It is 240 hours divided by eight, spread across people and selected tasks. It is not 30 school days, 43% of a teacher’s year, a reduced headcount or a cash saving. A pilot should time the same tasks, include review, failures, retries and setup, then report distributions and costs.

## What is actually live on the public link?

The real interface, saved H/outing outputs, source navigation and interactive Devin exercise. The public preview disables new provider sessions and native writes. The native PRONOTE action was recorded in its Windows environment. A reviewer can test the web experience without our credentials; a new native run requires the configured backend and interactive desktop.

## What happens in the parent view?

Grégory sees Alex and Lucas together. The summary and next actions refer to same-child sources. Alex’s displayed **3/6 is an exercise mark**, not an overall grade or an invented average. No Lucas grade is supplied by the current records. The family view is read-only. The prototype’s role switch is a demonstration persona, not production authentication or authorization.

## Did a real Stripe payment happen?

No real charge is claimed. The product contains a Stripe Checkout adapter and signed-webhook handling with offline contract tests; the filmed payment journey is an isolated preview. An account-backed run remains to be completed with configured credentials. We should show the integration boundary clearly when asked, not treat a logo as proof of a transaction. [Payment states](outing-stripe-checkout.md).

## What about privacy, security and sovereignty?

The demonstration uses fictional records. The bounded Devin brief sends generic skill labels rather than the pupil report. The exercise is sandboxed, offline and network-blocked. Source references are checked against the child/case. We use cloud providers; we do not claim French-only hosting, certification, production GDPR compliance or production RBAC. A school deployment needs appropriate contracts, access controls, retention, audit and operational review. Local hosting of selected components is an architectural option, not a completed sovereignty claim.

## How much does it cost? What is the business model?

We have not measured complete per-task operating cost or willingness to pay. A plausible pilot is an institution subscription with bounded provider budgets and cached preparations; validate it against measured active time, completion rate, support burden and API/VM cost. Do not infer revenue or cash savings directly from the time model. Avoid quoting an unfinished API billing reading as zero cost.

## What is the technical contribution?

A working integration: application-context triggers, concurrent preparations, custom tool contracts, native software operation, read-back comparison, constrained source selection and role-specific presentation. The exercise adds an observable research-to-design-to-code chain. This is a systems prototype and evaluation starting point, not a new foundation model or proof of universal autonomy.

## What would you do next?

Run a small teacher/parent pilot with paired timed tasks; expand failure-mode coverage; verify a configured Stripe sandbox; implement real identity/authorization; measure latency and cost; test delayed learning outcomes. Keep the integration modular: API when available, computer use when the interface is the appropriate operational boundary.

## Why does the film show €120M?

It is a full-adoption scenario for secondary teachers, not a measured budget saving. DEPP reports 485,450 secondary teachers. Applying our modelled 6.0555 hours per year gives 2.94M hours; valuing them at an assumed €40/hour gives €117.6M, rounded to €120M. Costs and other actors are excluded.
