# Calli pitch deck: speaker notes

Generated by `docs/pitch/build_deck.py`; slide text and notes live there.

## 1. An assistant that works alongside you.

Calli uses the context of the current task to prepare useful work in parallel, then combines functions and computer use to carry out an explicit request in existing software. Education is the first demonstrated application; New Pronote is its role-specific interface. Observation currently covers registered document openings inside Calli, not the whole desktop. Real screenshot: New Pronote Today, commit 2c1f5a4.

## 2. Observe. Prepare. Act.

A registered document opening inside Calli provides context. A preparation starts against a frozen case and validated sources while the user continues working. Independent school-trip collectors can run concurrently when H requests them. On explicit dictation, the native writer uses Holo and bounded functions to operate PRONOTE. These are separate flows: opening a document does not silently write a comment. Python owns the queue, checks and journal. The product demonstrates this mechanism in education; it does not claim universal desktop observation.

## 3. A dictated comment lands in real PRONOTE, then is read back.

Flow of the recorded run: the teacher dictates; Gladia transcribes; Python checks pupil, course, text and STOP; Holo (H computer use) takes one item through next_item, navigates, types, saves, reads the cell back and calls report_result; Python compares and journals. Queue to verified: 25.57 s for one recorded item (docs/calli-api-and-architecture.md). The recorded pupil is Lucas Bernard from the native trial roster. One item is not a reliability study.

## 4. Function calling does the structured work, in parallel.

Structured work runs through tools, not pixels: transcription (Gladia), source search (Linkup), validation against sources (H managed agent, 97.31 s, session e1f16a50). For a school outing, Holo started three collectors concurrently: route, museum and class roster (run 23025b24ce29, partial draft in 90.22 s). Calendar and payment are separate steps; payment is a simulation and neither is part of this concurrent trace.

## 6. An estimated 43% less active entry time.

43% is the rounded median of the declared input-sensitivity model, not a measured human comparison or a share of all working hours. The annual teacher median is 6.0555 hours across selected tasks. Scaling to 485,450 secondary teachers gives 2.94 million hours; at an assumed EUR40/hour this is EUR117.6 million of gross time value, rounded to 3M hours and EUR120M. This assumes complete adoption and excludes technology costs. No cash saving or net ROI is established.

## A. Backup · National impact, with explicit assumptions.

DEPP 2026 reports 47,000 primary schools, 7,000 colleges, 3,700 lycees and 485,450 secondary teachers. Establishment count is context; secondary-teacher headcount is the multiplier. Workload assumptions stay those of the previous model. 100,000 input samples describe sensitivity, not statistical confidence. At 10% adoption the same scenario is about 294,000 hours and EUR11.8 million gross time value; costs and other actors are excluded. See docs/national-impact-scenario.md.

## C. Modernize the experience. Keep the installed application.

New Pronote is a new task-oriented interface. Holo 4 drives the installed PRONOTE desktop while Python owns structured jobs, functions, validation and the journal. We do not modify the native executable or database. This is a UI retrofit, not a cloned PRONOTE backend. The demonstrated integration is one desktop writing flow, not a universal connector.

## D. Use the best integration for each operation.

An API or CLI is preferred when a supported interface exposes the needed operation with adequate access and guarantees. MCP exposes capabilities implemented by a server; it does not create a missing vendor operation. INDEX EDUCATION documents export services and connectors. We have not established that PRONOTE has no APIs, nor that writing an MCP server is impossible. Our native demonstration operates a particular installed desktop flow through its existing UI. Sources: https://modelcontextprotocol.io/docs/learn/architecture and https://telechargement.index-education.com/fr/pronote-info1420-services-export-de-donnees.php
